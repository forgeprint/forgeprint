Forgeprint

Tell your agent who you are and what you are building — get back one blueprint and a setup recipe it can execute.

Pre-release. The catalog is empty and this page is a placeholder. The browsable site is generated from index.json in phase 3 of the roadmap.

What it is

  • A curated catalog of project blueprints, one folder each.
  • A resolver that takes your languages and goals and returns exactly one blueprint — not a list to browse.
  • A deterministic setup.md per blueprint: numbered steps, pinned versions, a verification command after each one.
  • A quality gate on every contribution: schema, setup test, duplicate report.
