## Published from a tag, with no token

`forgeprint publish <version> --trusted` packs each package with pnpm — so
`workspace:*` becomes a real version — and publishes the tarball with npm,
which is the client that performs the OIDC exchange with the registry.
`forgeprint release <version> --skip-npm` stops after the tag and the GitHub
release, and pushing that tag is what starts
[`release.yml`](https://github.com/forgeprint/forgeprint/blob/main/.github/workflows/release.yml). No secret exists anywhere
on that path, nothing expires between releases, and npm attaches provenance by
itself.

The half that cannot live in a repository is a trusted publisher configured on
npmjs.com for each package, matched on the workflow **filename**. Getting that
field wrong returns `E404 Not Found - PUT`, which reads as "no such package"
and means "the exchange was refused" —
[`docs/releasing.md`](https://github.com/forgeprint/forgeprint/blob/main/docs/releasing.md) says so in the place somebody
will be standing when it happens.

The laptop path is unchanged and is not deprecated. Actions being unavailable
delays a release; it does not block one.

## A recipe nobody had ever run

Worth writing down, because it is the one failure the quality gate is supposed
to make impossible.

`rails-web-app` was merged at 1.0.0 while `setup-test` was still waiting for
Ruby on the runner. The recipe had therefore never been executed, and it held
four defects, each hidden behind the one before it:

| Step | What was wrong                                                                                  |
| ---- | ----------------------------------------------------------------------------------------------- |
| 14   | `Fugit` was never required — a lazy transitive dependency, and Zeitwerk autoloads app, not gems |
| 23   | `bin/brakeman` carries `--ensure-latest`, so it exited 5 the day Brakeman 8.1.0 shipped         |
| 28   | all four production `database:` paths were commented out, so `db:prepare` killed the container  |
| 29   | the health check printed sixty identical `curl` lines and nothing about the container           |

`main` was red for seven days before anybody noticed, which is its own
finding: Actions failure notifications are now configured and
[`docs/repo-settings.md`](https://github.com/forgeprint/forgeprint/blob/main/docs/repo-settings.md) records what each signal
does and does not cover. Steps 29 to 31 of that recipe ran for the first time
on 2026-10-05.

The lesson is already enforced elsewhere: a recipe whose `setup-test` cannot
run is a recipe that has not been tested, whatever the rest of CI says.

## Tools

### forgeprint

- **`publish --trusted` and `release --skip-npm`**, above.
- **Rule 9 keys an expert on `role + domain + seniority + languages`**
  ([ADR 0015](https://github.com/forgeprint/forgeprint/blob/main/docs/decisions/0015-experts-per-language.md)). The triple
  alone meant one architect held every language. `languages` compares as a
  set; an expert naming none is the stack-neutral one, and there is still
  exactly one of those per triple. A language-specific expert must have
  checklists about its language.
- **`lint-setup` refuses a write step whose target is not a file.** A step
  whose sentence ended on `storage` took the directory as its path and died
  with `EISDIR` inside a container, twenty-four steps in. The rule now reads
  the path through the same function the runner uses, because two
  implementations of it had already disagreed. `test-setup` catches what no
  shape check can see — a plausible path that is a directory on disk.
- **The package registries of Flutter, Phoenix, Gradle and Android**, and an
  `xmlns` value is read as a name rather than a host, so the
  `schemas.android.com` declaration every Android manifest must carry
  verbatim is no longer an unencrypted fetch.
- **A secret written into an install command is caught, and a long variable
  name is not.** It used to flag any twenty-character run and look for
  `=NAME=`, which never occurs — so a real literal passed and
  `SAMPLE_SERVICE_CLIENT_SECRET_VALUE=$...` failed.
- **Resolving options keeps the blank lines inside code blocks**, so a recipe
  that writes Python no longer loses the spacing ruff requires.
- **`gh` output and the distribution manifests are parsed, not cast.** An
  error body could read as a list of no CI runs; a wrong manifest field could
  pass silently. Both go through a schema now.
- **Two publish failures survive pnpm's line wrapping**, which had split "not
  running in an interactive terminal" across lines and matched nothing. The
  fixtures are pnpm's own output, pasted rather than retyped.
- **An expired MCP Registry token under an organization** is told to use a
  `read:org` PAT, not the browser login that cannot see the organization.

### forgeprint-mcp

- **All ten tools declare annotations.** Under the specification's defaults a
  client may treat every call as destructive and open-world and ask for
  approval each time. This server installs nothing and runs nothing, so all
  ten are read-only, non-destructive, idempotent and closed-world from one
  shared constant, asserted by a test for every listed tool.
- **The catalog fetch times out** after 15 seconds. It had no timeout, so a
  stalled network held a tool call open indefinitely.
- **The package README lists all ten tools**, their annotations and the
  protocol revisions the SDK negotiates. It had listed six and no protocol.

Both were found by running this repository's own `agent-designer` and
`typescript-backend-engineer` experts against the server they describe.
