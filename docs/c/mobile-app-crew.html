crews/mobile-app-crew

Mobile App Crew

Assembled by @aliosmanmho

A React Native app on Expo built to its SDK, audited with a screen reader on a device, gated end to end, and released with a version that never changes and a way to withdraw it.

✓ Claude Code· Codex CLI· GitHub Copilot CLI· Cursor· Gemini CLI· Windsurf· Cline· OpenCode· Kiro

What it is for

Building and shipping a React Native app on Expo: SDK-aligned dependencies and secure storage, a screen-reader audit on a device, end-to-end journeys on an emulator, and a release and OTA plan that says how it is withdrawn.

Where it is wrong

A Flutter or native Android app, backend work, store listing copy, or a change to one screen. One screen is small, same-file work for the mobile engineer alone.
