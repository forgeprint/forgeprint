crews/code-review-crew

Code Review Crew

Assembled by @aliosmanmho

Four reviewers, one lens each, whose findings end as one list with one verdict: correctness, security, performance and the tests in the change.

✓ Claude Code· Codex CLI· GitHub Copilot CLI· Cursor· Gemini CLI· Windsurf· Cline· OpenCode· Kiro

What it is for

A pull request or diff large enough to cross several concerns, reviewed through separate lenses (correctness, security, performance, tests) and merged into one finding list with one verdict.

Where it is wrong

Writing the code, style-only linting, or a diff of a few lines or a single file. One reviewer reads that faster than four can hand it round, and the extra lenses find nothing the first did not.
