API Hardening Crew

Assembled by @aliosmanmho

Three specialists for an API that already has users, where the job is finding what is wrong rather than deciding what to build.

✓ Claude Code· Codex CLI· GitHub Copilot CLI· Cursor· Gemini CLI· Windsurf· Cline· OpenCode· Kiro

What it is for

Hardening an API that is already in production: finding the authorization gaps, making the suite worth gating on, and turning a rollback from a belief into a tested path.

Where it is wrong

A greenfield project, where there is nothing to harden yet and the decisions worth taking are architectural rather than defensive.
