Docs Crew

Assembled by @aliosmanmho

A documentation set with a shape CI can hold: typed sections and no orphan pages, a reference generated from a linted OpenAPI document, and pages whose samples were run.

✓ Claude Code· Codex CLI· GitHub Copilot CLI· Cursor· Gemini CLI· Windsurf· Cline· OpenCode· Kiro

What it is for

Building or restructuring the documentation for a codebase or SDK: the information architecture and a docs build CI can fail, an API reference from a linted contract, and guides, tutorials and ADRs whose samples run.

Where it is wrong

Marketing copy, translation, or fixing one page or one README. That is small, same-file work for the technical writer alone.
