Context7 mcp

Library documentation at the version in use, fetched on demand instead of recalled from training.

Third-party software. Forgeprint hosts none of this code: it is an installation recipe for a project somebody else publishes and maintains. Review the permissions below before installing.

What it can reach

Sends the library name and your query to Context7's service and returns documentation.

It needs no secret.

Install

claude-code

claude mcp add-json context7 '{"command":"npx","args":["-y","@upstash/context7-mcp@4.1.1"]}'

codex

codex mcp add context7 -- npx -y @upstash/context7-mcp@4.1.1

gemini-cli

gemini mcp add context7 npx -y @upstash/context7-mcp@4.1.1
