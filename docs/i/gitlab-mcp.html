integrations/gitlab-mcp

GitLab MCP Server mcp

GitLab's built-in MCP server (beta): projects, work items, merge requests and pipelines on your own GitLab instance or GitLab.com.

Third-party software. Forgeprint hosts none of this code: it is an installation recipe for a project somebody else publishes and maintains. Review the permissions below before installing.

Upstream

Projecthttps://gitlab.com/gitlab-org/gitlab
Pinned atgitlab-18.6
Verified on2026-09-24

What it can reach

Signs in as you through OAuth with the mcp scope and acts with your GitLab permissions: reads projects, work items, merge requests and pipelines, and can commit, open and merge merge requests, and run or delete pipelines.

It needs no secret.

Install

Claude Code

claude mcp add -s user --transport http GitLab "https://<your-gitlab-host>/api/v4/mcp"

Codex CLI

codex mcp add GitLab --url "https://<your-gitlab-host>/api/v4/mcp"

Gemini CLI

gemini mcp add -t http GitLab "https://<your-gitlab-host>/api/v4/mcp"

Only agents whose command syntax has been verified are listed. A missing agent is one nobody has confirmed, not one that does not work.
