AWS Documentation MCP Server mcp

Search, read and get recommendations from the public AWS documentation, with no AWS credentials.

Third-party software. Forgeprint hosts none of this code: it is an installation recipe for a project somebody else publishes and maintains. Review the permissions below before installing.

Upstream

Projectawslabs/mcp/tree/main/src/aws-documentation-mcp-server
Pinned at1.2.1
Verified on2026-09-24

What it can reach

Reads pages on docs.aws.amazon.com and calls AWS's public documentation search and recommendation APIs; it holds no AWS credentials and reaches no account.

It needs no secret.

Install

Claude Code

claude mcp add-json aws-documentation '{"command":"uvx","args":["awslabs.aws-documentation-mcp-server==1.2.1"],"env":{"FASTMCP_LOG_LEVEL":"ERROR","AWS_DOCUMENTATION_PARTITION":"aws"}}'

Codex CLI

codex mcp add aws-documentation --env FASTMCP_LOG_LEVEL=ERROR --env AWS_DOCUMENTATION_PARTITION=aws -- uvx awslabs.aws-documentation-mcp-server==1.2.1

Gemini CLI

gemini mcp add aws-documentation -e FASTMCP_LOG_LEVEL=ERROR -e AWS_DOCUMENTATION_PARTITION=aws uvx awslabs.aws-documentation-mcp-server==1.2.1

Only agents whose command syntax has been verified are listed. A missing agent is one nobody has confirmed, not one that does not work.
