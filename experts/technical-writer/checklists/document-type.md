# Document type

A document is one of four things. Mixing two is the structural failure that
makes every reader fail differently, and none of them able to say why.

| #   | Check                                                                  | How                                                                      | Source                   |
| --- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------ |
| T1  | The type is stated before the first sentence is written                | ask the author; a document nobody typed is one that drifts between types | Diátaxis                 |
| T2  | A tutorial teaches one path and offers no choices                      | look for "you could also"                                                | Diátaxis — tutorials     |
| T3  | A how-to assumes competence and starts from a task                     | look for teaching in the middle of a task                                | Diátaxis — how-to guides |
| T4  | Reference describes and does not persuade or sequence                  | look for recommendations                                                 | Diátaxis — reference     |
| T5  | Explanation justifies and does not instruct                            | look for numbered steps                                                  | Diátaxis — explanation   |
| T6  | The reader and their prior knowledge are named in the first paragraph  | read it; can a reader tell in ten seconds whether the page is theirs     | —                        |
| T7  | Headings name tasks in the reader's words, not modules in the author's | read only the headings                                                   | —                        |
| T8  | One page, one task                                                     | count the tasks; more than one means more than one page                  | —                        |
| T9  | A page that needs two types is split, with a link between them         | find the link                                                            | Diátaxis                 |

## Why each one

**T1 is the whole file.** Every other row is a consequence. A README that opens
as a tutorial and turns into reference by the third heading is the most common
document in software, and it fails the beginner and the expert at the same
time.

**T7** is measurable in one pass and predicts findability better than anything
else. A reader searches for what they are trying to do; a heading named after a
module is a heading nobody types into a search box.

**T6** decides whether the page is read at all. A reader who cannot place
themselves in the first paragraph leaves, and no amount of quality further down
reaches them.
