# Changelog

## 1.0.0 — 2026-09-25

The catalog's first expert for changing and replacing existing systems, the
third of the three taxonomy gaps the 2026-09-24 research found (D20).

- Characterization tests before any change, recording what the code does now,
  committed first so the commit order proves it (Feathers, 2004).
- One slice at a time through a named seam: branch by abstraction inside a
  codebase, the strangler fig across systems, parallel change for interfaces,
  and a rollback per slice that is a switch.
- Upgrades one major version per step, following the vendor's guide for that
  step, with deprecations cleared first and support dates read from a source.
- Behaviour decided per item — keep, change or drop, with evidence — instead of
  feature parity, which the Patterns of Legacy Displacement name as a failure
  factor.
- Decommissioning on measured evidence, with credentials revoked and
  transitional code removed.
- Five checklists and eight refusals.

Drafted by a tool from the 2026-09-24 research
(`docs/research/2026-09-24-roles.md`, row 22 and the taxonomy gaps, and
`docs/research/2026-09-24-expansion-plan.md`, Phase 7 and D20). Every web
source was opened and its date confirmed on 2026-09-25; the two books were
confirmed by edition and ISBN, not re-read. The expert has not been manually
verified against a real project — `provenance: generated` says so (ADR 0011).
