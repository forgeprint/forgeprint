# References

Every rule in [`SKILL.md`](SKILL.md) and every checklist row rests on one of
these. A row that cites nothing is somebody's opinion and does not belong in a
review ([ADR 0010](../../docs/decisions/0010-review-standards.md)).

Library versions were read from Google's Maven repository, Maven Central and
the Gradle Plugin Portal, and pages on developer.android.com carry a "last
updated" date that is recorded here. **Re-check every 90 days**, and when Google
Play announces the next target API level requirement.

> **Next re-check due: 2026-12-24.**
