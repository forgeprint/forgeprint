# Check understanding

Understanding is shown by the learner doing something, not by the learner
saying "got it". Read against the transcript.

| #   | Check                                                                                                            | How to find it in the transcript                                | Source                                                                                      |
| --- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| CU1 | Each concept taught is followed by one short exercise                                                            | count concepts and exercises                                    | Anderson and Krathwohl (eds.), _A Taxonomy for Learning, Teaching, and Assessing_, 2001     |
| CU2 | Each exercise is labelled with its revised Bloom's level: remember, understand, apply, analyse, evaluate, create | the label appears with the exercise                             | Anderson and Krathwohl 2001; Krathwohl, _A Revision of Bloom's Taxonomy: An Overview_, 2002 |
| CU3 | Exercise levels climb over a session for the same concept                                                        | the sequence of labels for one concept                          | Krathwohl 2002                                                                              |
| CU4 | The learner's attempt comes before any solution                                                                  | a learner turn precedes the solution                            | Roediger and Karpicke, _Test-enhanced learning_, 2006                                       |
| CU5 | Feedback names what was right first, then points to the line that is wrong                                       | the feedback turn mentions a line number or quotes the line     | Anderson and Krathwohl 2001 (assessment aligned to the objective)                           |
| CU6 | The next session or topic opens with a recall question answered without looking                                  | the first mentor turn of the segment asks for recall            | Roediger and Karpicke 2006                                                                  |
| CU7 | "Does that make sense?" is never the only check                                                                  | grep the transcript; each occurrence is followed by an exercise | Roediger and Karpicke 2006 (retrieval, not rereading, predicts retention)                   |

## Why each one

**CU4 and CU6 are retrieval practice.** Roediger and Karpicke found that
taking a test produced better retention after a delay than studying the
material again. An exercise whose solution is shown first is restudy, not
retrieval.

**CU2** makes an exercise's purpose checkable. "What does this print?" is
_understand_; "write a function that does this" is _apply_ or _create_. An
unlabelled exercise cannot be judged too easy or too hard.

**CU7** catches the most common false check: a learner saying yes to "does
that make sense" tells the mentor nothing about whether it did.
