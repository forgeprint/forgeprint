# Graduated hints

When the learner is stuck, the smallest help first. Read against the
transcript: find each moment the learner says they are stuck and follow the
next few mentor turns.

| #   | Check                                                                                         | How to find it in the transcript                                          | Source                                                                                                                   |
| --- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| GH1 | The first reply to a stuck learner is a hint, not the answer                                  | the turn after "I'm stuck" contains no complete solution                  | Aleven, Roll, McLaren and Koedinger, _Help Helps, But Only So Much_, 2016                                                |
| GH2 | Hints escalate in order: concept, place, parallel example, answer                             | successive hints get more specific; none skips straight to the last level | Aleven et al. 2016 (levels of on-demand hints ending in a bottom-out hint)                                               |
| GH3 | The answer is given only after the learner has attempted at least one earlier hint            | a learner attempt sits between the last hint and the answer               | Baker, Corbett, Koedinger and Wagner, _Off-Task Behavior in the Cognitive Tutor Classroom_, 2004                         |
| GH4 | After an answer is given, the learner is asked to explain why it works                        | the next mentor turn asks for an explanation                              | Atkinson, Renkl and Merrill, _Transitioning from studying examples to solving problems_, 2003 (self-explanation prompts) |
| GH5 | A learner asking for "just the answer" repeatedly is told once what the ladder is for         | one plain explanation, not a lecture each time                            | Baker et al. 2004                                                                                                        |
| GH6 | A hint points to an idea or a line, never contains the corrected code at the first two levels | read the first two hints for code blocks                                  | Aleven et al. 2016                                                                                                       |

## Why each one

**GH1 is the default an agent gets wrong.** Asked a question it can answer, an
agent answers it. For a learner, that answer is the one reply that guarantees
they will be stuck on the same thing next time.

**GH3** is the guard against drilling to the bottom. Baker and colleagues
found gaming the system — including reaching answers through the help — was
the off-task behaviour most strongly associated with reduced learning.

**GH4** turns a given answer back into learning: the learner has to rebuild
the reasoning the hints would have led them through.
